# Verdant Siege — branding art

All images here are **original**, generated by project scripts (no stock art, no AI image generation):

| File | Size | How it is made |
|---|---|---|
| `icon_foreground.png` | 1024², transparent | `Tools/Blender/branding.py -- icon` (Cycles render of the project's own Sunspore + Glowcap models leaning around a glowing heart-seed built with `vskit`) + `branding_compose.py` (warm glow, soft mask to the central 66 % safe zone) |
| `icon_background.png` | 1024², opaque | `branding_compose.py`: radial gradient deep moss `#0E2E1C` → green → warm sunlit centre, subtle leaf silhouettes |
| `icon_legacy.png` | 1024², rounded corners (8 %) | foreground composited on background |
| `logo.png` | 2048×1024, transparent | `branding.py -- logo`: extruded/bevelled 3D text "VERDANT / SIEGE" in **Lilita One** (SIL Open Font License, `Assets/_Game/UI/Fonts/LilitaOne-OFL.txt`), gold→sunlit gradient face, cream rim, dark-green outline; sprout + heart-seed motif; `branding_compose.py` adds a soft warm glow and drop shadow. Designed for a dark moss background `#142A1E`. |

Files starting with `_` are intermediate renders. Regenerate:
```
blender -b --factory-startup --python Tools/Blender/branding.py -- icon logo
python3 Tools/Blender/branding_compose.py
```
